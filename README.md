# Trading Game

Учебная агентная модель рынка BTC/USD с лимитными заявками. Пятнадцать простых стратегий конкурируют за исполнение заявок; результат содержит цену, число сделок, комиссии и стоимость портфеля каждого агента на каждом шаге.

## Быстрый запуск

Нужен Python 3.10+; внешние пакеты для симуляции не требуются.

```bash
python simulation.py --steps 500 --agents 100 --seed 42 --output results.csv
python -m unittest discover -s tests -v
```

`--seed` делает прогон воспроизводимым. `results.csv` создаётся локально и не добавляется в Git. Для сравнения стратегий можно открыть CSV в Excel или pandas. Четыре старых XLSX файла были результатами отдельных прогонов исторического скрипта и не служили тестовыми данными.

## Как работает модель

Агенты выставляют заявки по одной из 15 эвристик. На каждом шаге списки покупателей и продавцов сортируются по лучшей цене, пересекающиеся заявки исполняются по средней цене двух лимитов. С покупателя и продавца списывается комиссия `0.05%`; доступный остаток проверяется **с учётом комиссии**. Каждые пять шагов появляются внешние заявки, поэтому сумма активов агентов сама по себе не сохраняется. Если сделок нет, цена сохраняется с небольшим случайным дрейфом.

Это демонстрация механики сопоставления заявок, а не модель реальной биржи, инвестиционная стратегия или оценка доходности. Начальные балансы и рыночная ликвидность заданы искусственно. Исходный эксперимент сохранён в `legacy/TradingGame.py` для сравнения; он использовал глобальное состояние, писал XLSX и открывал интерактивные графики.
